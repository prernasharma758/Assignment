CSS Box Model

The CSS Box Model describes how elements are displayed on a webpage. It consists of four main parts.

Content

This is the content area of the box.

Four Parts of Box Model

  • Content: The actual text or image inside an element.
  • Padding: Space between content and border.
  • Border: A line surrounding the padding and content.
  • Margin: Space outside the border.

Conclusion

The box model helps control the size, spacing and layout of HTML elements.
